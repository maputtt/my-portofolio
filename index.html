02 — case study

Server kantor kena malware?
Santai, gua beresin. 🧹

Bukan cuma hapus script jahat — gua bongkar arsitekturnya biar kejadian yang sama ga keulang.

root@ugm-prod: ~
$ scan --deep /var/www
⚠  malicious scripts found in panel & resources
$ sanitize --all && restore --seo
✓  malware cleaned, SEO restored
$ isolate --wordpress vultr --ci3 rumahweb
✓  environments split → 2 separate VPS
$ cloudflare enable --waf --ssl --dns
✓  edge protection: ON
$ status
●  all systems stable. aman, bos. ▌
  • 2 VPSWordPress & CodeIgniter dipisah biar kalo satu kena, yang lain aman
  • 100%script jahat disapu bersih + SEO dipulihin
  • WAF + SSLCloudflare jagain server dari depan
