02 — case study

Office server got hacked?
Relax, I cleaned it up. 🧹

Not just deleting bad scripts — I rebuilt the architecture so the same thing can't happen again.

root@ugm-prod: ~
$ scan --deep /var/www
⚠  malicious scripts found in panel & resources
$ sanitize --all && restore --seo
✓  malware cleaned, SEO restored
$ isolate --wordpress vultr --ci3 rumahweb
✓  environments split → 2 separate VPS
$ cloudflare enable --waf --ssl --dns
✓  edge protection: ON
$ status
●  all systems stable. aman, bos. ▌
  • 2 VPSWordPress & CodeIgniter split apart, so if one gets hit the other stays safe
  • 100%malicious scripts wiped + SEO restored
  • WAF + SSLCloudflare guarding the servers at the edge
